# Social preview image

This folder holds the **recommended** Open Graph / repository card image (`repo-social-preview.jpg`).

GitHub does not offer a public API to set the social preview. To use it on the repository:

1. Open **Settings** → **General** → **Social preview** → **Edit** → **Upload an image…**
2. Choose `repo-social-preview.jpg` from this folder (under 1 MB; use a 2:1 canvas such as 1280×640 for best cropping).

After uploading, social platforms may cache the old card for a while; use their post inspectors if you need a forced refresh.
